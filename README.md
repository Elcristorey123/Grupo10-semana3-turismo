## 🌿 Estrategia de trabajo colaborativo (Git)

| Rama               | Responsable  | Contenido                                    |
| ------------------ | ------------ | -------------------------------------------- |
| `main`             | Ambos        | Versión final integrada                      |
| `dev/integrante-1` | Integrante 1 | Pasos 1, 2 y 3 (Setup, Navbar, Hero)         |
| `dev/integrante-2` | Integrante 2 | Pasos 4, 5 y 6 (Grid, Formulario, Auditoría) |

### Flujo de trabajo

1. Cada integrante trabaja en su rama.
2. Al terminar, crea un **Pull Request** a `main`.
3. El compañero revisa (**Code Review**) y aprueba.
4. Se hace **Merge** resolviendo conflictos.

## 🎨 Combinación Bootstrap + Tailwind

Este proyecto integra **dos frameworks CSS** de forma híbrida:

- **Bootstrap** → componentes preensamblados (navbar, grid, formularios).
- **Tailwind** → utilidades atómicas (sombras, gradientes, hover, spacing).
